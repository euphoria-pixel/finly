# Аудит и план

На старте: Python CLI `main.py` (PyMuPDF + Natasha) обезличивает текст PDF;
`llm_pipeline.py` обрабатывает его через OpenAI-совместимый endpoint, валидирует
CSV, разбивает текст на части, кэширует ответы. Эти модули сохранены.
`charts.py` строит прежние PNG-графики из CSV; тоже сохранён.

Уже существовали FastAPI `backend/app.py`, SQLite/SQLAlchemy `backend/db.py`,
единый ingestion в `services.py`, Decimal-нормализация в `schemas.py`,
целочисленный бюджет `budget.py`, симулятор `simulator.py` и SSE.
Импорт: загрузка → очистка PDF → проверка текста пользователем → LLM → CSV →
редактируемый предпросмотр → явное подтверждение → транзакции.
Были тесты парсера, обезличивания, импорта, бюджета, симулятора и T-API.

Frontend: Next.js App Router, React, TypeScript, Recharts, Lucide,
Radix Button, CSS с адаптивностью и двумя темами; 10 страниц в общем компоненте.
README отсутствовал, команды запуска — `scripts/dev.py`, миграция и seed.

1. Сохранить CLI, LLM-пайплайн, импорт, аналитику и интерфейс.
2. Вывести T-API из активного backend/UI; исторические файлы не удалять.
3. Подключить Bank-in-a-Box отдельным read-only HTTP-адаптером и локальной инфраструктурой.
4. Добавить миграцию MCC, публичное source_transaction_id, серверный demo-Pro.
5. Связать polling, идемпотентный ingestion, бюджет, уведомления и SSE.
6. Добавить воспроизведение/сброс, достоверные AI-объяснения и проверки.
